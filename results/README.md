# Results

`baseline.json` is the standardized, cooldown-controlled reference run for both model packings. `baseline_initial_uncontrolled.json` preserves the first diagnostic pass, which is not used for comparisons. `raw/` stores exact stdout/stderr for each llama-bench invocation and model smoke run. Nsight Systems reports, SQLite exports, compact kernel summaries, and CUDA object resource reports live under `profile/`.
